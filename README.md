# Analogue Clock

This is a simple **Analogue Clock** built using **HTML**, **CSS**, and **JavaScript**. The clock displays the current time with moving hour, minute, and second hands, offering a visually appealing and functional demonstration of JavaScript's `setInterval` method and CSS animations.

---

## 🚀 Features

- **Real-Time Time Display**: Shows the current time in hours, minutes, and seconds.
- **Smooth Animation**: The hands of the clock move smoothly in real-time.
- **Responsive Design**: The clock adjusts to different screen sizes for optimal viewing.

---

## 🎨 Technology Stack

- **HTML**: Provides the structure for the clock's container and hands.
- **CSS**: Used for styling the clock and implementing animations for the hands.
- **JavaScript**: Controls the real-time movement of the clock hands using `setInterval` and dynamic time fetching.

---

## 📋 How to Use

1. **Clone the Repository**:  
   ```bash
   git clone https://github.com/<your-username>/Analogue-Clock.git
   ```

2. **Open the File**:  
   Open the `index.html` file in your preferred browser.

3. **Enjoy the Clock**:  
   The clock will automatically show the current time with the moving hands of the clock.

---

## 🛠️ How It Works

- The time is retrieved using JavaScript's `Date()` method.
- CSS animations are used to rotate the clock hands based on the current time, and `setInterval()` ensures the clock updates every second.
